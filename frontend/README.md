# Frontend for [personal-website](https://martonaron.dev)

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

This starts only the Vite frontend. In development and production it connects
to the separately deployed API at `https://api-personal.martonaron.dev`.

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
